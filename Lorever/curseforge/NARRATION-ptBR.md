## Description (English)

Lorever Narration (Português do Brasil)

A natural Brazilian Portuguese storyteller voice for the Lorever narrator.

Lorever already reads its pages aloud with the game's own text to speech. This optional pack replaces that robotic voice with a calm, natural Brazilian Portuguese storyteller. Every region, figure, people, event, book and letter in Lorever has already been narrated, so there is nothing to set up and nothing else to run.

How it works

1. Install Lorever and this pack.
2. Open any Lorever page and press the play button of the narrator.
3. That is all. The narrator uses the pack by itself.

Good to know

- Lorever is required. The CurseForge app installs it for you.
- The pack is used when Lorever shows its content in Portuguese. To switch the language: /lorever language pt
- In the narrator panel (/lorever narrator) you can choose the voice: Automatic, the game's built-in voice, or this voice pack. Automatic picks this pack when it is installed.
- If a line has no recording (for example, after a Lorever update adds new text), the game's own voice reads that line. Nothing breaks.
- No program runs outside the game. The pack is only sound files and a small index.
- Fully compatible with Questie.

What is inside

- The pack holds only Lorever's own text, read aloud. It contains no audio, text or art from Blizzard Entertainment, and no text from the game's books.
- The files are Ogg Vorbis audio, kept small to save disk space.

AI disclaimer

The voice in this pack was generated by a text to speech model, not recorded by a person. The recordings were made on the author's own computer with Kokoro-82M, an open model released under the Apache 2.0 license, using its "Santa" voice at 1.30 speed. The text that is read is Lorever's own lore, written for the add-on. No online AI service was used, and no real person's voice was cloned or imitated.

Other languages

Each Lorever language has its own separate, optional pack: English, Português (Brasil), Deutsch, Français and Español.

## Native text (optional, below the English one)

Summary: Uma voz de contador de histórias para o Lorever: cada página de lore e cada livro, lidos em português natural. Add-on opcional, precisa do Lorever.

Lorever Narration (Português do Brasil)

Uma voz natural de contador de histórias para o narrador do Lorever.

O Lorever já lê as páginas em voz alta com a voz do próprio jogo. Este pacote opcional troca essa voz robótica por um contador de histórias calmo, em português do Brasil. Todas as regiões, figuras, povos, eventos, livros e cartas do Lorever já estão narrados. Não há nada para configurar e nenhum programa extra para abrir.

Como funciona

1. Instale o Lorever e este pacote.
2. Abra qualquer página do Lorever e aperte o botão de play do narrador.
3. Pronto. O narrador usa o pacote sozinho.

Bom saber

- O Lorever é obrigatório. O app do CurseForge instala ele para você.
- O pacote é usado quando o Lorever mostra o conteúdo em português (/lorever language pt).
- No painel do narrador (/lorever narrator) você escolhe a voz: Automático, a voz do jogo ou este pacote de voz. O Automático usa este pacote quando ele está instalado.
- Se uma frase não tiver gravação (por exemplo, depois de uma atualização do Lorever com texto novo), a voz do jogo lê essa frase. Nada quebra.
- Nenhum programa roda fora do jogo. O pacote tem só arquivos de som e um pequeno índice.
- Totalmente compatível com o Questie.

O que tem dentro

- O pacote tem só o texto do próprio Lorever, lido em voz alta. Ele não tem áudio, texto ou arte da Blizzard Entertainment, nem texto dos livros do jogo.
- Os arquivos são áudio Ogg Vorbis, pequenos para ocupar pouco espaço no disco.

Aviso sobre IA

A voz deste pacote foi gerada por um modelo de texto para fala. Não é a gravação de uma pessoa. Os áudios foram feitos no computador do autor com o Kokoro-82M, um modelo aberto sob a licença Apache 2.0, com a voz "Santa" na velocidade 1.30. O texto lido é o lore do próprio Lorever, escrito para o add-on.

Outros idiomas

Existe um pacote separado e opcional para cada idioma do Lorever.
