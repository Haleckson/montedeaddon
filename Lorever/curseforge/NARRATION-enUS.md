# Lorever Narration (English): CurseForge page

## Summary

A storyteller voice for Lorever: every lore page and book, read aloud in natural English. Optional add-on, needs Lorever.

## Description

Lorever Narration (English)

A natural storyteller voice for the Lorever narrator.

Lorever already reads its pages aloud with the game's own text to speech. This optional pack replaces that robotic voice with a calm, natural English storyteller. Every region, figure, people, event, book and letter in Lorever has already been narrated, so there is nothing to set up and nothing else to run.

How it works

1. Install Lorever and this pack.
2. Open any Lorever page and press the play button of the narrator.
3. That is all. The narrator uses the pack by itself.

Good to know

- Lorever is required. The CurseForge app installs it for you.
- The pack is used when Lorever shows its content in English.
- In the narrator panel (/lorever narrator) you can choose the voice: Automatic, the game's built-in voice, or this voice pack. Automatic picks this pack when it is installed.
- If a line has no recording (for example, after a Lorever update adds new text), the game's own voice reads that line. Nothing breaks.
- No program runs outside the game. The pack is only sound files and a small index.
- Fully compatible with Questie.

What is inside

- The pack holds only Lorever's own text, read aloud. It contains no audio, text or art from Blizzard Entertainment, and no text from the game's books.
- The files are Ogg Vorbis audio, kept small to save disk space.

AI disclaimer

The voice in this pack was generated by a text to speech model, not recorded by a person. The recordings were made on the author's own computer with Kokoro-82M, an open model released under the Apache 2.0 license, using its "Michael" voice at 1.30 speed. The text that is read is Lorever's own lore, written for the add-on. No online AI service was used, and no real person's voice was cloned or imitated.

Other languages

Each Lorever language has its own separate, optional pack: English, Português (Brasil), Deutsch, Français and Español.
