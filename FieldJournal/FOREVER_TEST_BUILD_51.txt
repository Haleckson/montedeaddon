WHAT THIS BUILD DOES
- Registers 77 verified Zephras Isle combat NPC IDs across 18 lore subjects.
- Covers wildlife, named/rare beasts, bandits, Al'Aketh, elementals, and faction-conflict mobs.
- Includes both ordinary and named variants when a reliable Forever NPC ID is available.
- Keeps all five lore tiers as "Lore entry pending." for the next dedicated lore-research pass.
- Preserves Zephras Isle as the single top-level client zone.
- Preserves all 27 Zephras Isle subregions already added in Builds 49-50.
- Does not register vendors, trainers, friendly quest givers, mounts, dead scenery NPCs, or other
  units that cannot normally trigger Field Journal's player-damaged UNIT_DIED encounter flow.
